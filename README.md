# Signal9 Prompt Studio

A prompt builder for AI image tools in the style of [Signal9 Studio](https://www.signal9studio.com.au).

Pick a portrait, landscape or building, start from a preset based on Signal9 works, adjust how the subject transforms and what surrounds it, and copy a prompt formatted for Midjourney, Stable Diffusion, Flux or DALL·E and similar tools.

Everything runs in the browser from a single HTML file. Prompts are assembled from built-in word banks and templates, so no AI service is called and no tokens are used. Saved prompts are kept in your browser's local storage.

## Use it

Open `signal9-prompt-studio.html` in any browser, or use the GitHub Pages site for this repository.
